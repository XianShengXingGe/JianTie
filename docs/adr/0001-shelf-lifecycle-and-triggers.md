# 0001. Shelf 暂存架生命周期、多屏与触发机制

## 上下文

简贴的 Shelf 模块旨在提供极简、无干扰的 Finder 文件临时中转体验。我们需要确定其在多 Stack 堆叠、Action 触发后状态变更、多显示器切换、原文件失效降级以及空状态唤出策略。

## 决策

1. **多 Stack 垂直流**：Shelf 允许多个 Stack 同时暂存，垂直排列，超出屏幕可用高度时支持平滑滚动。
2. **Copy Path 移除语义**：用户将文件/Stack 拖入 `Copy Path` 区域后，执行路径复制并立即将该 Stack 从 Shelf 移除（与 AirDrop 成功一致，视为本批次中转完毕）。
3. **多屏动态跟随**：在多显示器环境下，Shelf 始终在当前鼠标/拖拽所在的活动显示器边缘（默认左侧）滑出，保证最短拖拽距离。
4. **失效静默清除**：当原文件被删除、彻底移动或外接磁盘卸载导致 Reference 失效时，Shelf 采取静默自动清除策略，不展示失效占位或弹窗打扰。
5. **纯鼠标驱动 (Mouse-Only)**：Shelf 默认不分配全局快捷键，完全由 Finder 拖拽开始（Drag Start）与屏幕边缘悬停（150ms 停留滑出、移出 600ms 无操作自动收回）触发。
