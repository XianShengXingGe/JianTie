# 0003. Clipboard 存储容量、回贴交互与记录策略

## 上下文

剪贴板模块需要确定数据持久化保留策略、鼠标直接操作行为以及剪贴板监听范围。

## 决策

1. **容量限制与无时间淘汰**：默认最大存储上限为 1000 条记录，默认不设置时间过期限制；达到 1000 条上限时采用先进先出 (FIFO) 策略自动剔除最旧的历史记录。
2. **纯粹完整捕获 (Faithful Capture)**：剪贴板监听模块对系统剪贴板产生的文本、富文本与图片进行真实、完整的时间流记录，不因特定来源 App 做静默过滤。
3. **鼠标对齐键盘回贴 (Click-to-Paste)**：在面板中鼠标单击任意 Item 直接触发回贴（Direct Paste）并关闭面板，交互语义与键盘 `Enter` 保持完全一致；悬停在条目上提供便捷的局部删除（✕）操作。
