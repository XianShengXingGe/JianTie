# 0002. Clipboard 快捷唤出与交互工作流

## 上下文

简贴的 Clipboard 历史面板是 Keyboard-first 场景，追求极高的唤出速度与流畅的击键肌肉记忆，避免与 macOS 原生或主流 IDE/开发工具的复杂修饰键快捷键产生冲突。

## 决策

1. **唤出方式**：采用全局**双击 `⌘` (Double-tap Command)** 唤出 Clipboard 历史面板，降低多键组合记忆负担与快捷键冲突概率。
2. **键盘优先链路**：
   - 双击 `⌘` → 聚焦搜索框并高亮最新第一条记录。
   - `↑` / `↓` 进行项目选择切换。
   - `Enter` 键确认 → 面板自动隐去，光标焦点瞬间归还给此前活动 App 并自动触发直接回贴（Direct Paste）。
   - `ESC` 键取消 → 面板直接关闭并归还原 App 焦点，不修改系统剪贴板。
